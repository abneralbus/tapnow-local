# Agent 一键整理

画布左下角「一键整理」向当前 Agent 发送内置整理规则。此次请求覆盖完整画布，忽略当前选中/引用范围，不混入之前的对话；草稿输入保留。按钮将 Agent 权限切换为仅移动、连接和断开连接。生成、修改提示词、增删节点均不授权。

Agent 获得全部节点的真实 ID、标题、完整文本/提示词、绑定引用、坐标、实际测量的卡片宽高、状态、生成参数和全部连线。素材像素尺寸单独标注；未知卡片尺寸标记为 null。不会发送 Key、Token、媒体文件地址或媒体文件本身。媒体内容仍不是视觉输入，模型不能声称已看过视频。

支持的 API 将背景和动作协议放入系统指令；Codex CLI 使用 developer instructions，Claude CLI 使用 system prompt。AGY 当前接口仅能前置文本，不能保证等同系统级优先级。上下文不再按节点数或字符数静默截断；模型供应商仍有其自身上下文和输出容量。

## 默认整理规则

- 只根据明确的 @图片/视频引用建立上游到下游依赖；没有提示词的节点不猜测入向依赖。
- 编号辅助先后，不为编号创建连线。整体左到右、分支错开，不强制网格。
- 相邻步距尽量 450—800，结合实际卡片尺寸避让；跨分支长连线不限于 800。
- 全节点提供位置动作；同时核对旧线，保留正确线，断开错误线后补齐依赖。
- 不修改节点文字、提示词、名称、素材，不增删节点，不生成素材。
- 先澄清未解决的矛盾；回复动作是“待执行”方案，由应用实施，不能提前声称完成。

执行前校验节点覆盖、明确引用集合、编号先后、上游方向、卡片重叠和内容完整性。失败则整批不应用；请求期间画布发生改变也会拒绝旧方案。执行前保存历史版本，执行后保存并复核；间距提示和需要人工判断的分支可读性单独报告，不冒称所有审美目标已经自动验证。

Agent 动作支持 `move`、`connect`、`disconnect`、`create`、`delete`、`prompt`、`generate`，各自受权限控制。动作批次与创建引用线不设 20 项上限。
